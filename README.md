# 书店小管家

腾讯方向二、场景3：业务智能体。独立本地模拟门店，不改动旧PHP、腾讯课堂项目或晴行。

## 启动与测试
需要 Node.js 24 或更高版本。在项目根目录运行以下命令，启动后打开 [书店小管家](http://127.0.0.1:14160/)。

```powershell
npm ci
npm start
```

依赖安装完成后，也可双击 `START.cmd` 启动。默认监听本机 14160 端口。另开终端执行 `npm test` 可复现本地业务、模型协议和 HTTP 集成测试。

- **本地演示**使用预设工具动作，可查库存、预览并确认模拟订单。无需模型配置或模型调用。
- **Agnes 模型**需要支持 OpenAI 工具调用的模型。将 `.env.example` 复制为 `.env`，按密钥签发区域填写 `MODEL_BASE_URL`、`MODEL_NAME` 和 `MODEL_API_KEY` 后重启。密钥保留在本机。当前真实验收使用 Agnes 中国站和 `agnes-2.5-flash`。
- **调用边界**为每轮最多 4 次模型请求、6 次工具执行。真实请求会向已配置的模型服务发送当前会话消息和工具结果，实际用量见供应商控制台。

## 来源和限制
B001/B002 根据旧 PHP 图书作业的种子字段整理，出版信息未核实。其余 22 条为虚构教学样例。价格、库存及订单均为教学模拟。
不导入旧账号、密码、.env或课堂向量库。SQLite保存在runtime，重启复用，不重置库存。
浏览器使用 Cookie 保存本地会话标识，有效期 30 天。使用同一浏览器及同一地址，服务重启后可继续查询会话订单。清除 Cookie 或换浏览器会开始新会话。这不是正式账号，仅供本机演示。
