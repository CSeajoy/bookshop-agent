# 腾讯 AI Coding 课程作业验收对照

选题为**方向二「AI 应用创新」场景 3「业务智能体」**。书店小管家模拟店员查询可售库存、预览订单、确认后扣减库存并查询订单的流程。对照依据为《腾讯AI Coding 课程作业.pdf》第 4 页场景要求、第 5 页交付清单和第 6 页评分表。

核心业务流程已实现，SDK 真实模型验收和 14 项自动化测试已有记录。作品介绍 PPT 已完成，封面待补团队信息。GitHub/Gitee 仓库链接、浏览器实页演示和 XBuddy 使用证据仍待补。

## 场景 3 功能

| 手册要求 | 当前证据 | 待补或限制 |
| --- | --- | --- |
| AI SDK 调用 2–3 个业务工具，串起自然语言、工具调用和汇总 | `search_books` 查库存、`preview_order` 生成预览、`get_order` 查订单。门店规则检索单独作为辅助工具。Agnes 已真实调用查库存和预览工具，查订单覆盖在本地测试 | 答辩时可展示自然语言触发一次工具调用和生成结果 |
| OpenAI 兼容工具调用透传和结果回传 | `gateway.mjs` 提供 AI SDK 与原生 Fetch 适配，`agent.mjs` 按工具调用 ID 回传结果。独立 `POST /v1/chat/completions` 有 JSON 与 SSE 模拟透传测试 | 真实验收覆盖网页后端使用的 SDK 工具链。网页聊天使用内部适配层，独立 HTTP 网关的真实供应商 SSE 和 Fetch 适配仍待复验 |
| 参数校验、异常处理、幂等与边界 | 数量上限、库存检查、过期和价格变化测试、会话隔离、重复确认。确认时在 SQLite 事务内计算金额和扣减库存 | 本机演示用浏览器会话管理订单 |
| 可视化执行链路与需求拆解 | 助手输入框下方的执行记录按编号展示处理请求、调用工具、返回结果。单据区展示确认状态及扣减前后库存 | 浏览器实页点击和演示留证待补 |
